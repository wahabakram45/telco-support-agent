# Parental Controls

Parental controls help you manage what your children can view on their mobile devices. They are designed to block adult content while keeping mobile data browsing safer.

## Cost
Parental controls are **free on all lines**. You don’t need to pay anything to enable them.

## What they block
Parental controls **block adult content on mobile data**. This means adult content won’t be accessible when a device is using mobile data.

## How to set them up
You can set up parental controls **in the TelcoX app**. Once you enable them, you can protect the settings with a **4-digit PIN**.

## PIN protection
The **4-digit PIN** helps prevent changes to parental control settings without permission. If someone doesn’t know the PIN, they can’t adjust the controls.

## Mobile data only (not Wi‑Fi)
Parental controls apply to **mobile data only**, and **do not apply to Wi‑Fi**. So, content access when connected to Wi‑Fi isn’t controlled by parental controls.

If you’re managing device use at home, it can be helpful to remember the difference between mobile data and Wi‑Fi so expectations match how the controls work.
